This project focused on turning a dense set of metrics and workflows into a clean dashboard that product and operations teams could use without friction.

### Highlights

- Data-first design with clear information hierarchy
- Focus on task completion and KPI visibility
- Responsive UI patterns built for fast scanning

### Outcome

The dashboard simplified team decision making and removed noise from recurring reporting workflows.
